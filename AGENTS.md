# READ THIS FIRST: this website has TWO language versions

ملخص بالعربي: الموقع له نسختين، إنجليزي وعربي. أي تعديل في الكلام أو الأقسام لازم يتعمل في اللغتين.

## How it works

- `index.html` is the ONLY file you edit. It is the English page and the source of truth.
- Every translatable element has two attributes: `data-en="..."` and `data-ar="..."`.
  The visible text inside the element equals the `data-en` value.
- `ar.html` is the Arabic page. It is GENERATED from `index.html` by `build_ar.py`.
  **Never edit `ar.html` by hand.** Your changes will be overwritten.
- `sitemap.xml` is also generated by `build_ar.py`. Do not edit it by hand.

## Rules for every change

1. Changing any text: update the visible English text, `data-en`, AND `data-ar` of the same element.
2. Adding a new section, card, button, list item, FAQ question, or link: write its Arabic in `data-ar`.
   An element without `data-ar` stays English on the Arabic page, and Google will read it as English.
3. Adding a new element that has no text (image, video): add `alt` text, and put the Arabic alt in the same
   way the existing images do if the page has one.
4. Do not edit anything between `TM-I18N-HEAD:BEGIN/END` and `TM-I18N-TAIL:BEGIN/END`. Those blocks are
   generated (canonical, hreflang, language button).
5. Do not rename the localStorage key `tiamo-lang`. The site scripts read it.
6. After editing `index.html`, run `python build_ar.py`. If you cannot run it, say so in your answer.
   The GitHub Action in `.github/workflows/build-ar.yml` also runs it on every push that changes `index.html`.
7. Arabic copy: simple, clear, natural. Keep brand names and tool names (Photoshop, VFX, WhatsApp) in Latin letters.
8. In your final answer, tell the owner which elements you changed in both languages.

## Do not

- Do not add a second copy of the page by hand.
- Do not create `ar/index.html`. The Arabic page lives at `ar.html` in the root so every relative path keeps working.
- Do not remove `data-ar` attributes to "clean up" the code. They are the Arabic content.
