# Tiamo Universe — تجربة مستقلة

## مهم قبل الرفع
- هذا المشروع مستقل تمامًا، ولا يحتوي على `index.html` الخاص بالموقع الأساسي.
- ارفع **محتويات هذا المجلد داخل مجلد جديد اسمه `universe`** في جذر مستودع GitHub.
- لا ترفع `index.html` الموجود هنا إلى جذر المستودع.
- بعد الرفع سيكون رابط التجربة عادة:
  `https://2020tiamo2020-del.github.io/Tiamo-Mohamad-Portfolio-ULTIMATE/universe/`

## تشغيل محلي
من داخل هذا المجلد شغّل:
```powershell
py -m http.server 8000
```
ثم افتح:
`http://localhost:8000`

## الملفات
- `index.html` واجهة التجربة.
- `universe.css` التصميم والواجهات.
- `universe.js` مشهد Three.js والحركة والتفاعل.

## ربط الأيقونة بالموقع الأساسي
لم أعدّل موقعك الأساسي في هذه الحزمة. بعد أن ترسل لي **ملف index.html الحالي من جذر المستودع** سأضيف أيقونة Universe في موضعها الصحيح بجوار اللغة وواتساب، وأسلمك ملف `index.html` المعدّل وحده. لن أطلب منك استبدال أي ملف آخر دون ضرورة.

## مصادر الوسائط
تُحمّل الصور والفيديوهات من المسارات العامة الموجودة في نسخة GitHub Pages المشار إليها داخل `universe.js`. إذا كانت بعض الملفات غير موجودة في تلك النسخة أو كانت امتدادات الفيديو مختلفة، ستحتاج خريطة الأصول إلى مطابقة دقيقة قبل اعتماد النسخة النهائية.
